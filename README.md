# AI Resell Assistant

DepopやeBayで見つけた海外の古着を **BUY&SHIP** で日本へ送り、**メルカリ**などで売るときの「仕入れ判断・利益計算・在庫管理」を手伝うWebアプリです。

> 現在は **Phase 1（MVP）** です。AI機能はまだ入っていません（Phase 2 で追加予定）。

---

### 外部サービスの制約で実装しないこと

- **Depop / eBay の自動取得**: 無断スクレイピングは行いません。eBay は公式API（Browse API、開発者登録が必要）が使えるため Phase 3 で検討します。Depop は一般公開のAPIが確認できていないため、手入力のままです。
- **メルカリの相場自動収集・自動出品**: 一般向けの公式APIがなく、規約上の制約があるため行いません。ユーザーが確認した価格を手動で登録します。
- **自動購入・メッセージ自動送信**: 行いません。交渉文はコピーして自分で送る形にします。

## Windows での始め方

> 用語メモ
> - **ターミナル**: 文字でパソコンに命令する画面。Windows では「PowerShell」を使います。
> - **Node.js**: このアプリを動かすためのソフト。`npm` というコマンドが一緒に入ります。
> - **Git**: プログラムの変更履歴を管理するソフト。GitHub からコードをダウンロードするのにも使います。

### 1. 必要なソフトを入れる（最初の1回だけ）

1. **Node.js（LTS版）** を入れる
   - https://nodejs.org/ja を開き、「LTS」と書かれた緑のボタンからダウンロード → インストーラーを「次へ」で進めます。
2. **Git** を入れる
   - https://git-scm.com/download/win からダウンロード → 基本的に「Next」で進めてOKです。
3. （おすすめ）**Visual Studio Code**（コードを見るためのエディタ）
   - https://code.visualstudio.com/

入ったか確認します。スタートメニューで「PowerShell」と検索して開き、次を1行ずつ入力して Enter：

```powershell
node -v
npm -v
git --version
```

それぞれ `v22.x.x` のようなバージョン番号が出ればOKです（Node.js は 20 以上が必要）。

### 2. コードをダウンロードする

```powershell
cd $HOME\Documents
git clone https://github.com/kaname1208/kaname1208.git ai-resell-assistant
cd ai-resell-assistant
git checkout claude/ai-resell-assistant-9s705h
```

### 3. 部品（ライブラリ）をインストールする

```powershell
npm install
```

数分かかります。`added ... packages` と出れば完了です。

### 4. アプリを起動する

```powershell
npm run dev
```

`Local: http://localhost:3000` と表示されたら、ブラウザで **http://localhost:3000** を開きます。
止めるときは PowerShell で `Ctrl + C` を押します。

### 5. 最初にやること

1. 画面左の **設定** を開き、
   - 「最新の参考レートを取得」で為替レートを更新（または手入力）
   - **BUY&SHIP の料金表**を、BUY&SHIP公式サイト／アプリの送料計算で確認した金額に書き換える（初期値は未確認のサンプル値です）
2. **商品を登録** で、Depop / eBay の商品ページを見ながら入力 → 右側（スマホでは下）に予想利益が出ます → 保存
3. 商品詳細画面で、メルカリで見つけた類似商品の **売却済み価格** を登録すると、相場の中央値が想定販売価格として使われます

### iPhone から使う（同じWi-Fi内）

```powershell
npm run dev -- -H 0.0.0.0
```

PowerShell で `ipconfig` を実行し、「IPv4 アドレス」（例: 192.168.1.10）を確認して、iPhone の Safari で `http://192.168.1.10:3000` を開きます。
Windows のファイアウォールの確認が出たら「プライベートネットワーク」のみ許可してください。
※ Phase 1 はログイン機能がないため、**インターネットには公開しないでください**。

## 利益計算のしくみ

```
予想利益 ＝ 想定販売価格 − 仕入れ総原価 − 国内販売関連費用
利益率   ＝ 予想利益 ÷ 想定販売価格 × 100
```

- **仕入れ総原価** = 商品代金 + 現地送料 + 為替・決済手数料 + 購入代行手数料（使う場合）+ BUY&SHIP国際送料（同梱時は重量で按分）+ 関税 + 輸入消費税 + その他経費
- **国内販売関連費用** = 販売手数料（メルカリ10%）+ 国内発送費 + 梱包資材費
- 関税は「(商品代金 + 現地送料 + 国際送料) × 関税率」、輸入消費税は「(課税価格 + 関税) × 10%」で**推定**します。実際の請求額が分かったら商品ごとに「実額」を入力してください。
  - 転売目的の輸入は、個人使用の特例（課税価格を6割で計算）の対象外です。
  - 課税価格1万円以下の少額免税は、ニット製衣類（Tシャツ・スウェットなど）が対象外のため、初期設定では適用しません。
- 各費用には **確認済み / 推定 / 未入力** の印がつきます。未入力がある場合は「未確定（参考値）」と表示され、判定は「判定不可」になります。

初期設定（すべて設定画面で変更可）: 最低予想利益 3,000円 / 最低利益率 30% / 仕入れ上限 10,000円 / 交渉開始 出品価格の75% / 最大交渉 90%（利益条件を優先）

## 開発者向け

```powershell
npm run dev     # 開発用サーバー
npm test        # 利益計算などの自動テスト
npm run lint    # コードの書き方チェック
npm run build   # 本番用ビルド
```

- データは `data/db.json` に保存されます（Gitには含まれません）。バックアップはこのファイルをコピーするだけです。
- 技術構成: Next.js 16 (App Router) / TypeScript / Tailwind CSS 4 / Vitest
- 設計・フォルダ構成・データベース設計: [docs/design.md](docs/design.md)
